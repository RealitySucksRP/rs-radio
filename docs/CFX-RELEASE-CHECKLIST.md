# Cfx free-release checklist

Package-side items completed in v1.0.0:

- `fxmanifest.lua` with current `cerulean` FX version.
- No deprecated `lua54 'yes'` directive.
- No `__resource.lua`.
- No license-token gate or Discord acquisition requirement.
- No remote code loading/execution.
- No mandatory database dependency.
- Readable source included.
- GPL-3.0-or-later license included.
- Server-side validation for privileged/gameplay actions.
- Current Enhanced voice path uses Cfx server-owned voice channels.
- OneSync declared as a dependency.
- Installation, compatibility, security, and voice-backend docs included.
- Backup/development files excluded from the release archive.

Before creating the forum topic, the author still needs **live evidence that cannot be generated by static source review**:

1. Start the exact release archive on a current FXServer artifact.
2. Capture idle and active `resmon` values or a profiler screenshot.
3. Capture at least one clear screenshot or a short demonstration video.
4. Test two real clients talking on the same channel.
5. Test a restricted channel with an allowed and denied player.
6. On Enhanced, verify `voice_internal` works with `sv_mumble` **not** enabled.
7. On Legacy, test the configured `pma-voice` version.
8. Run the ownership regression with two RS radios: A joins 101 -> B joins 666 -> close A -> verify the provider remains on B/666 and B can still PTT.
9. Repeat with three controllers: Police -> Gang -> Zombie; close the two stale radios and verify only the current owner can disconnect voice.
10. Test one third-party pma radio takeover; RS Radio must stand down and closing its old UI must not write channel 0.
11. Run `/rsradiostate` during the switches and confirm owner, provider channel, confirmed channel and generation agree.
12. Confirm every bundled image/sound is owned by RealitySucksRP or licensed for redistribution.
13. Upload the ZIP directly, use a public Git repository, or use another distribution path allowed by the current Cfx release rules.

Do not publish invented resmon numbers. Cfx specifically asks release authors for performance indicators.
